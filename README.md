# database-app-practice

## 概要
COACHTECH 教材 Tutorial 9-3「データベース操作ハンズオン演習」で作成した成果物です。
Laravelを使用して商品データを管理する仕組みを作成しました。マイグレーションとシーダーによるデータ登録、クエリビルダを使ったデータ取得を実装しています。

## 使用技術
- PHP 8.x
- Laravel 10.x
- MySQL
- マイグレーション、シーダー、クエリビルダ

## 学んだこと
- マイグレーションによるテーブル作成と、シーダーによる初期データの登録方法
- Modelを使用したデータベース操作と、Eloquent・クエリビルダの違い
- Controllerで取得したデータをViewに渡し、ルーティングで画面と処理をつなぐ方法
